# Yan AI Solutions

Site estático institucional de **yan.net.br**, desenvolvido com HTML, CSS e JavaScript puros.

## Estrutura

- `index.html` — página inicial
- `servicos.html`, `solucoes.html`, `contato.html` — páginas institucionais
- `blog/` — base editorial, sem artigos publicados
- `privacidade.html`, `termos.html` — páginas legais
- `css/`, `js/`, `images/` — recursos compartilhados

O formulário de contato está preparado para ser conectado a um serviço de envio ou backend antes da publicação.
